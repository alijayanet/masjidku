METHOD 2: Install via ADB (untuk yang familiar)
─────────────────────────────────────────────────────────
1. Enable USB Debugging di device:
   Settings → Developer Options → USB Debugging

2. Connect device ke komputer via USB

3. Buka Command Prompt/Terminal

4. Jalankan command:
   adb install MasjidKU-TV_v1.0_20260827_145014.apk

5. Tunggu sampai muncul "Success"

6. Buka aplikasi di device

❓ TROUBLESHOOTING:

Problem: Aplikasi force close
Solution:
- Clear cache: Settings → Apps → MasjidKU-TV → Clear Cache
- Clear data: Settings → Apps → MasjidKU-TV → Clear Data
- Reinstall aplikasi

Problem: Remote control tidak connect
Solution:
- Pastikan device & HP di WiFi yang sama
- Cek firewall tidak block port 8080
- Restart aplikasi
- Scan ulang QR Code

Problem: Jadwal sholat tidak akurat
Solution:
- Pastikan kota sudah dipilih dengan benar
- Cek metode perhitungan di Settings
- Restart aplikasi untuk refresh data
