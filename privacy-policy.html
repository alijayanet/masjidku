1. Komitmen Privasi & Prinsip Zero Tracking

Aplikasi MasjidKU TV berkomitmen penuh menjaga privasi pengurus DKM dan jamaah masjid. Aplikasi ini dirancang dengan prinsip 100% Bebas Pelacakan (Zero Tracking) dan Penyimpanan Lokal (Local Storage).

Kami TIDAK mengumpulkan, merekam, memperjualbelikan, atau membagikan informasi data pribadi pengguna ke server pihak ketiga mana pun.

2. Informasi & Data yang Digunakan

A. Data Konfigurasi Masjid & Keuangan

Seluruh data masjid (Nama Masjid, Jadwal Sholat, Petugas Sholat Jum'at, Laporan Saldo Kas Keuangan, dan Teks Maklumat) hanya disimpan secara lokal di memori internal perangkat TV Anda melalui SQLite/Room Database Android. Data tidak pernah diunggah ke internet publik.

B. Gambar QRIS Infaq & Logo

Gambar kode QRIS infaq yang diunggah pengurus melalui remote HP disimpan secara offline di media internal aplikasi TV dan hanya digunakan untuk keperluan tampilan donasi jamaah di layar TV tersebut.

C. Lokasi Koordinat Sholat

Koordinat lintang dan bujur kota yang Anda pilih digunakan secara lokal oleh rumus hisab astronomi untuk menentukan jadwal sholat yang akurat. Kami tidak melacak lokasi fisik perangkat TV Anda.

3. Izin Akses Perangkat (Permissions)

Izin (Permission) Tujuan Penggunaan
android.permission.INTERNET Mengambil sinkronisasi jadwal sholat resmi dari API Kemenag RI serta menjalankan server lokal untuk remote control HP.
android.permission.ACCESS_NETWORK_STATE Mengecek koneksi jaringan Wi-Fi lokal.
android.permission.ACCESS_WIFI_STATE Menampilkan alamat IP lokal TV (contoh: 192.168.1.15:8080) agar pengurus dapat menghubungkan Web Remote HP.
android.permission.WAKE_LOCK Menjaga layar TV tetap aktif menyala selama jam operasional masjid.

4. Fitur Web Remote Smartphone (Jaringan Lokal)

Fitur Web Remote menggunakan server HTTP internal di dalam TV yang hanya dapat diakses melalui jaringan Wi-Fi lokal yang sama. Tidak ada koneksi yang diteruskan ke server luar atau internet publik.

5. Bebas Iklan & Pelacak Pihak Ketiga

Aplikasi MasjidKU TV 100% bebas dari iklan komersial (tanpa Google AdMob, Unity Ads, atau analitik pihak ketiga) demi menjaga kekhusyukan dan kenyamanan ibadah di rumah ibadah.
